# Profiling artifacts

Generated by `uv run python -m benchmarks.profiling.run --benchmark all`.

| File | Contents |
|------|----------|
| `scorer_scaling.csv` | Per-pair `score_pair` cost vs `n`, per scorer and data kind. |
| `driver_scaling.csv` | `as_penalty_matrix` cost vs `p` with `pearson_abs` fixed, isolating O(p^2) dispatch overhead. |
| `end_to_end.csv` | Full `MRMRSelector.fit` cost at representative `(n, p)`. |
| `*_after.csv` | The same grids re-run after the Phase 2 optimizations. |

`status` values: `ok` (measured), `skipped_projected_cost` (projected past the
per-cell budget; `projected_s` records the projection), `error` (the cell
raised — investigate, do not ignore).

Timings are machine-specific. Only the *ratio* between a baseline file and its
`_after` counterpart is meaningful across machines.
